# По порядку — To-Do List

Небольшой адаптивный сайт для личного списка задач. Тестовое задание, выполненное с помощью OpenAI Codex.

## Возможности

- Добавление задачи кнопкой «+» или клавишей Enter.
- Отметка выполнения и возврат задачи в работу.
- Удаление задач.
- Сохранение задач и их состояния после перезагрузки страницы через `localStorage`.
- Поддержка клавиатуры, подписанные элементы управления и сообщения для скринридера.

## Запуск

Рабочий сайт: https://mihailkashintsev.github.io/todo-list-ai-test/

Для локального запуска нужен только Python 3:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000. Устанавливать зависимости для самого приложения не нужно. Используйте HTTP-сервер, а не открытие HTML через `file://`.

## Реализация

HTML, CSS и обычный JavaScript без фреймворков и сборки. Для четырёх основных операций этого достаточно. Текст задачи вставляется через `textContent`, поэтому HTML в пользовательском вводе не исполняется. Пустой ввод не создаёт задачу; длина ограничена 300 символами.

Данные хранятся только в текущем браузере и не отправляются на сервер. Между устройствами они не синхронизируются; очистка данных сайта удаляет список. Если сохранение не удалось, приложение показывает ошибку и сохраняет введённый текст. Повреждённые данные не перезаписываются без явного согласия начать новый список.

## Проверка

Проверено в настоящем браузере Google Chrome через Playwright: добавление, пустой ввод, безопасный вывод текста, переключение выполнения, удаление, сохранение после перезагрузки, мобильная ширина 375 px, ошибка записи и повреждённые данные.

Для повторного запуска автоматической проверки нужны Node.js, Python 3 и установленный Google Chrome:

```sh
npm install
npm test
```

Зависимость Playwright нужна только тестам. Тест сам запускает локальный сервер на порту 8766 и закрывает его после проверки.

## Использование AI

OpenAI Codex использован для подготовки интерфейса, написания HTML/CSS/JavaScript, обработки ошибок хранения и автоматических браузерных проверок. Готовый интерфейс проверен по скриншотам на компьютере и мобильной ширине; основные сценарии выполнены в Chrome. Claude Code и Cursor в этом задании не использовались.
