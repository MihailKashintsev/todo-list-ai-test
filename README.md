# По порядку — To-Do List

Адаптивный список задач с аккуратным интерфейсом и анимациями. Тестовое задание, выполненное с помощью OpenAI Codex.

**Демо:** https://mihailkashintsev.github.io/todo-list-ai-test/

## Возможности

- Добавление задачи кнопкой или клавишей Enter; кнопка плавно появляется после ввода текста.
- Отметка выполнения с анимацией зачёркивания, возврат в работу.
- Фильтры «Все», «В работе» и «Выполненные».
- Удаление через 3 секунды с обратным отсчётом и возможностью отмены; затем распад на частицы и плавное смещение строк.
- Сохранение задач и отметок после перезагрузки через `localStorage`.
- Поэтапное появление страницы, прорисовка стрелки в пустом списке, индикатор прогресса.
- Мобильная версия, управление с клавиатуры, подписи и сообщения для скринридера.
- Поддержка `prefers-reduced-motion`: декоративные движения и частицы отключаются.

## Запуск

Нужен Node.js 22.12+ (проверено на Node.js 26).

```sh
npm ci
npm run dev
```

Открыть адрес, который выведет Vite (обычно http://127.0.0.1:5173).

```sh
npm run build    # готовый статический сайт в docs/
npm run preview # просмотр production-сборки
```

GitHub Pages публикует папку `docs/` из `main`. После изменения исходников нужно пересобрать её и закоммитить результат.

## Стек и анимации

React, Vite, CSS, GSAP и Web Animations API.

`src/components/AnimatedContent.jsx` — настоящий компонент **React Bits**, используемый для появления блоков страницы. Его исходник закреплён на конкретном коммите; ссылка и лицензия находятся в `licenses/`. Изменены только импорт React и ненужная в клиентском Vite-приложении директива `use client`.

Остальные эффекты написаны для этого интерфейса: SVG-стрелка, CSS-зачёркивание и появление кнопки, частицы через Web Animations API. Частицы — кратковременный неинтерактивный визуальный слой; реальные данные удаляются из хранилища только после трёхсекундного отсчёта. До его завершения удаление можно отменить; при закрытии страницы задача останется. После эффекта слой полностью удаляется.

## Данные и безопасность

Ключ хранения `po-poryadku.tasks.v1` и формат данных сохранены от первоначальной версии: ранее созданные задачи доступны после обновления. Текст отображается средствами React без HTML-инъекций. Пустые задачи не создаются; длина ограничена 300 символами. Встроенная браузерная валидация отключена — англоязычных всплывающих сообщений нет.

Данные хранятся только в текущем браузере, не синхронизируются между устройствами и удаляются при очистке данных сайта. Если запись не удалась, введённый текст и предыдущие задачи не теряются. Повреждённые данные не перезаписываются без явного согласия начать новый список.

## Проверка

Для тестов дополнительно нужны Python 3 и установленный Google Chrome:

```sh
npm test
```

Тест собирает production-версию, поднимает локальный сервер на порту 8766 и выполняет сценарии в Chrome через Playwright: все четыре основные функции, фильтры, трёхсекундное удаление, отмена и параллельные изменения во время отсчёта, перезагрузка, пробельный ввод, безопасный вывод текста, ошибки записи, восстановление повреждённых данных, мобильная ширина 375 px, выравнивание иконки, частицы, уменьшенное движение и совместимость со старым списком. Сервер и браузер закрываются после проверки.

## Использование AI

OpenAI Codex использован для дизайна интерфейса, написания React/CSS/JavaScript, интеграции React Bits, обработки ошибок и браузерных проверок. Десктопный и мобильный интерфейсы проверены по скриншотам. Claude Code и Cursor в этом задании не использовались.
